# Project 2 — Backend API Development

DecodeLabs Full Stack Industrial Training Kit (Batch 2026)

## Goal
Develop a simple backend API to handle application logic (Intern management).

## Key Requirements
- API endpoints (GET / POST)
- Handle user input and responses
- Validate basic data

## Endpoints
| Method | Route              | Description          |
|--------|--------------------|----------------------|
| GET    | /api/interns       | List all interns     |
| GET    | /api/interns/:id   | Get one intern by id |
| POST   | /api/interns       | Create a new intern  |

## Run

```bash
npm install
npm run dev
```

Server starts on `http://localhost:5000`.
